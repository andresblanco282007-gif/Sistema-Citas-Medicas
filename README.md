# Sistema de Citas Médicas (Sistema-Citas)

## 🎯 Objetivo
Diseñar, planificar y documentar una plataforma tecnológica centralizada para la gestión eficiente de citas médicas, optimizando la asignación de turnos entre pacientes, médicos y el personal administrativo, garantizando trazabilidad y control de calidad bajo estándares SQA.

## 📋 Descripción General
El **Sistema de Citas Médicas** es una aplicación orientada a la web y dispositivos móviles que permite a los pacientes agendar, reprogramar o cancelar citas con profesionales de la salud en diferentes especialidades. Asimismo, provee herramientas de gestión interna para que el personal de recepción y los médicos administren sus agendas y consulten historiales de atención médica de manera segura y centralizada.
